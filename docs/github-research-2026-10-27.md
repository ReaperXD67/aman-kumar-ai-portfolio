# GitHub profile direction — 27 October 2026

## Research decision

There is no defensible worldwide ranking of profile READMEs. The useful benchmark is an immediate, memorable identity followed by engineering proof that a reviewer can actually inspect. The selected direction builds on Aman's existing cinematic portfolio: a recognizable portrait, a finite signal-and-pixel entrance, clear professional routes, and a reading path organized around failure boundaries.

The profile does not acquire a dozen external image services. Its principal artwork is authored locally, committed with the profile repository, and has explicit mobile and reduced-motion versions. Ordinary Markdown retains every essential claim and link.

## Implemented in the profile repository

- A locally rendered signal-route header with the position “Autonomy needs an audit trail,” a prominent real portrait, and a 1.7-second top-to-bottom assembly that stops.
- Separate desktop/mobile assets and static reduced-motion choices, keeping the source photograph recognizable after the entrance.
- A failure-first project index: stale lease completion, weak retrieval evidence, and lost delivery acknowledgement route directly to the relevant source or live workbench.
- Updated Agent scope, unchanged flagship ordering, canonical Vercel and photo-free résumé links, existing provenance-backed badges, and ordinary visible skill vocabulary.

The separate `.github-profile-work` repository has its own Git history and remote. Publishing its README requires a commit and push to `ReaperXD67/ReaperXD67`; modifying the outer portfolio repository alone does not publish it. A README portrait and account avatar remain separate settings.

The link audit resolved 34 of 36 HTTPS destinations; LinkedIn and X are intentional manual checks. The published GitHub profile was checked for updated text and disclosure, responsive image loading, no page overflow at desktop/mobile, and reduced-motion still selection.
