## The idea

Most portfolios list claims. This one lets visitors inspect the system behind them.

The opening carries a fluid **Decision Loom** into a curved project world through one shared WebGL renderer and camera. The final KarixMC capture docks into its interactive **Engineering X-ray** lens; the proof band follows selected work. The inspected architecture seeds the **Validation Chamber**. From there, one open metallic surface unfolds through the portrait, professional evidence and contact, with a continuous camera path. These surfaces share a dark world while their native controls and readable content remain in normal flow. The **Systems Kernel** remains the portrait's optional second view.

## Engineering surface

- **Interface:** React 19, Vite, TypeScript/JavaScript, responsive semantic UI
- **Spatial system:** Three.js, React Three Fiber, Drei, postprocessing
- **Motion:** GSAP, Motion, scroll-linked timelines, reduced-motion fallbacks
- **Performance:** one demand-rendered opening stage capped at 1.8 million base pixels; the standalone hero retains a 2.2-million-pixel budget. The ending uses a separate transparent WebGL stage capped at 1.5 million backing pixels and DPR 1.35, with reusable mesh buffers and scroll-addressed rendering. GPU deformation, shared ribbon geometry, 6,800 desktop / 2,800 phone signals, instanced gates, offscreen/hidden-tab suspension, pause controls and finite portrait/trace/Method transfers bound the work. The main portrait is approximately 149 KiB with a 4.6 KiB first-screen thumbnail.
- **Typography:** Space Grotesk + JetBrains Mono
- **Delivery:** Vercel production deployment, Sites-compatible worker output, automated build verification

## Run locally

```bash
npm install
npm run dev
```

Production verification:

```bash
npm run build
npm run test:sites
npm run test:profile
npm run test:motion
```

The build must emit `dist/client/index.html`, `dist/server/index.js`, and `dist/.openai/hosting.json`.

`test:motion` checks 28 pure opening/ending route, freeform film/camera, capture-exclusion, contain-fit and Loom invariants. The 18 Sites/profile checks cover hosting and canonical identity assets, for 46 Node checks overall. These source/math checks complement browser verification; they do not establish visual quality or deployment status.

Production changes pass the Vite build and Sites worker contract before deployment. The public résumé uses one stable route and a versioned runtime manifest; releases verify that the deployed PDF is byte-identical to the canonical local artifact, so portfolio, GitHub, and recruiter links cannot silently drift apart.

The October 2026 refresh uses Aman's supplied yellow-kurta portrait with a charcoal studio background and identity-preserving lighting, plus new versioned 1200 × 630 shared-link artwork. The canonical résumé remains photo-free: one column, readable text, embedded fonts, and specific engineering decisions grounded in project sources. Recruiter actions precede the project detail cards; mobile professional links use full labels.
